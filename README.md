# 🧮 Financial Calculator

A C program that performs basic financial calculations—specifically simple and compound interest—using terminal-based inputs and custom formulas.

## 📚 Course Context

This project was created as the final for my **Computer Organization** course in **Fall 2023**. It reflects my understanding of core C programming concepts.

## 🔧 Features

- Menu-driven CLI interface for financial calculations
- Simple Interest: based on principal, rate, and time
- Compound Interest: adds compounding frequency into calculation
- Uses custom functions for cleaner modular design

## 💡 Technologies Used

- C
- `math.h` for power calculations
- Standard input/output handling
